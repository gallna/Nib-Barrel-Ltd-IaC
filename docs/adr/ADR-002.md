## ADR-002: Routing Globalny przez AWS Global Accelerator i Route 53 ARC

* **Status:** Zaakceptowany
* **Data:** 2026-11-22
* **Kontekst:** Ruch pochodzi głównie z sieci komórkowych (5 gier Android, 11,6M DAU), gdzie operatorzy często ignorują niskie wartości TTL rekordów DNS. Poleganie wyłącznie na DNS podczas awarii regionu złamałoby limit **RTO ≤ 15 min**.
* **Decyzja:** Ruch do wszystkich 4 API kierujemy przez **AWS Global Accelerator** (statyczne adresy Anycast IP) sterowany za pomocą **Amazon Route 53 Application Recovery Controller (ARC)**. Aplikację *Dienekes Plaza Web* wystawiamy przez **Amazon CloudFront** z automatycznym *Origin Failover*.
* **Konsekwencje:**
* **Pozytywne:** Przełączenie 100% ruchu między regionami zajmuje **~30 sekund** bez zmiany adresów IP po stronie klientów; sterowanie przez Route 53 ARC działa na płaszczyźnie danych AWS, więc pozostaje sprawne nawet przy awarii API zarządzającego regionu głównego.
* **Negatywne:** Dodatkowa warstwa sieciowa wymagająca konfiguracji i utrzymania w kodzie IaC.
